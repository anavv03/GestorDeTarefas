# 📝 App de Gestão de Tarefas (Task Manager)

Aplicação web completa para gestão de tarefas (*To-Do List*) desenvolvida com **Python**, **Flask** e **SQLite**. O projeto permite criar, listar, marcar como concluídas e eliminar tarefas em tempo real com uma interface responsiva.

---

## 🚀 Funcionalidades

- **Criar Tarefa:** Adiciona novas tarefas à base de dados.
- **Listar Tarefas:** Exibe todas as tarefas guardadas.
- **Concluir Tarefa:** Marca/desmarca a tarefa como realizada (com estilo *strikethrough*).
- **Eliminar Tarefa:** Remove a tarefa permanentemente do banco de dados.

---

## 🛠️ Tecnologias Utilizadas

- **Backend:** Python 3, Flask, Flask-SQLAlchemy
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, Bootstrap (Tema Sketchy / Bootswatch)
- **IDE:** Visual Studio Code
